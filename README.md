# 🏠 House Price Prediction System

A professional machine learning application that predicts residential property prices using advanced predictive analytics. The project demonstrates the complete machine learning lifecycle, including data preprocessing, feature engineering, model training, evaluation, and deployment through a Flask-based web application.

## Features

- Predicts house prices based on user inputs
- Data preprocessing and feature engineering
- Machine learning model training and evaluation
- Interactive Flask web interface
- Real-time prediction results
- Modular and scalable project structure

## Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Git & GitHub
